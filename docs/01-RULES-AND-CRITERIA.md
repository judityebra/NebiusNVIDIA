# 01 Rules and criteria

Purpose: official rules and judging criteria.

Source: read by Cowork on 2026-10-29 from https://nebiusglobalaihackathon.devpost.com/ . The full `/rules` page was not readable, so eligibility and IP stay `Status: Unconfirmed`; verify at https://nebiusglobalaihackathon.devpost.com/rules before submitting. A third-party listing (Startup Grants India) agrees on the points below.

## Official rules
- Build a working AI system on Nebius AI Cloud or Nebius Token Factory using at least one NVIDIA open-source model (e.g. Nemotron).
- Tracks: Coding and Agentic Engineering, Best Apps and Agents, Personal AI, Physical AI.
- Physical AI = embodied and edge agents that sense and act in the real world. Demo video: at least one minute showing hardware or, without hardware, the key application modules in action. No demo URL required.
- Full rules text: TODO read on Devpost. Status: Unconfirmed

## Judging criteria and weights
Technological Implementation (how well built, how effectively it uses Token Factory / AI Cloud and Nemotron), Design, Potential Impact, Quality of the Idea. The Devpost page gives no weights. Judges: engineers from NVIDIA and Nebius, plus Tavily staff (third-party listing).

## Eligibility
Individuals of age of majority, teams and organisations; most countries, excluding sanctioned territories. Details behind Devpost sign-up. Status: Unconfirmed

## IP and licence
- Code must be public under Apache 2.0, MIT or MPL 2.0. Our repo is MIT (copyright Judit Yebra).
- IP ownership terms: not stated in sources. Status: Unconfirmed

## Submission requirements
- Working project + selected track, detailed description.
- Public YouTube demo video, 3 minutes or less. Physical AI: at least 1 minute showing hardware operating, or the key application modules in action when there is no hardware.
- Working demo URL: not required for Physical AI.
- Public repo with an Apache 2.0, MIT or MPL 2.0 licence and a README explaining how NVIDIA models and Nebius tools are used (setup steps included).
- Feedback on Nebius and NVIDIA tools; explanation of updates if the project pre-dates the hackathon.

## Dates and prizes
Deadline 2026-10-30 10:00 PDT (Oct 30 2026). Judging 1-15 Dec 2026, winners about 11 Jan 2027 (third-party listing).

Prizes: Grand $20,000, 2nd $10,000, 3rd $6,000, one NVIDIA Jetson Orin Nano per track winner, Best Use of Tavily $3,000, Most Valuable Feedback $100 x 10, City Winner $500 x 20 (in-person events only).
